# Neural Network from Scratch

This is a neural network implementation built from scratch using only NumPy. It trains on the MNIST dataset and demonstrates fundamental concepts in neural networks.

## Results
The model achieves decent accuracy on the test set after training. You can visualize the training process using the provided script.

## Usage
1. Run `data_loader.py` to download and prepare the MNIST dataset.
2. Use `train.py` to train the model on the dataset.
3. Run `visualize_training.py` to see the loss curve and accuracy.

## Requirements
- numpy
- matplotlib
